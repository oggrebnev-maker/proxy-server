# proxy-server

Прокси-сервер Xray (VLESS + Reality) одной командой на свежем VPS с Ubuntu 24.04.
Для Claude Code и других инструментов, недоступных из вашего региона. Та же ссылка работает
как личный VPN на телефоне и компьютере.

Без ИИ, без вопросов по ходу — один вопрос в самом конце.

## Что нужно

- VPS: 1 vCPU, 1 ГБ RAM, 10 ГБ диска, Ubuntu 24.04, публичный IPv4.
- Страна, где нужный сервис доступен (Нидерланды, Финляндия, Швейцария, Германия и т.п.).
- Доступ root по паролю от хостера.

## Установка

Подключитесь к серверу под root и выполните:

    bash <(curl -fsSL https://raw.githubusercontent.com/oggrebnev-maker/proxy-server/main/install.sh)

Скрипт сам:

1. обновит систему и поставит зависимости;
2. установит Xray и создаст конфигурацию VLESS + Reality (порт 443, маскировка под обычный сайт);
3. создаст пользователя `proxyadmin` с sudo и SSH-ключом;
4. включит firewall (открыты только SSH и 443), fail2ban, автообновления безопасности;
5. напечатает блок «ГОТОВО» с данными для подключения и сохранит их в `/home/proxyadmin/proxy-server/`.

Затем остановится с вопросом. Это единственное место, где нужно ваше участие.

## Последний шаг — подтверждение доступа

Перед тем как отвечать:

1. Скопируйте **приватный ключ** из вывода в Termius: Keychain → New key → вставить в поле Private key.
2. Добавьте хост: IP сервера, порт 22, пользователь `proxyadmin`, этот ключ.
3. Откройте **второе окно**, подключитесь. Выполните `sudo true`, введите пароль из блока «ГОТОВО».
4. Вошли и sudo сработал — вернитесь в первое окно, введите `yes`.

После `yes` вход root и вход по паролю по SSH отключаются. Первое окно не закрывайте, пока не
убедитесь, что второе продолжает работать.

Ответ не `yes` — ничего не меняется, прокси уже работает. Позже запустите скрипт снова: он сразу
перейдёт к этому шагу.

## Что вы получаете

В `/home/proxyadmin/proxy-server/` и на экране:

| Файл | Назначение |
|---|---|
| `README.txt` | логин, пароль для sudo, команда ssh, ссылка |
| `id_ed25519`, `id_ed25519.pub` | ключ SSH пользователя `proxyadmin` |
| `vless.txt` | ссылка `vless://…` для VPN-клиентов |
| `proxy.env` | готовый файл настроек прокси для `ai-starter` |

Скачать всё на компьютер: по SFTP под `proxyadmin` (папка `proxy-server`) или `scp -r proxyadmin@IP:proxy-server ./`.

## Как пользоваться

**VPN на телефоне/компьютере.** Hiddify, v2rayNG (Android), Streisand (iOS), Nekoray (Windows):
вставить ссылку из `vless.txt` или отсканировать QR-код из вывода скрипта.

**Claude Code на рабочем сервере.** Файл `proxy.env` кладётся в проект; `ai-starter` сам поднимает
локальный HTTP-порт через Xray-клиент и прописывает переменные прокси.

**Добавить свой ключ.** Зайдите как `proxyadmin` и выполните:

    echo "ssh-ed25519 AAAA... ваш публичный ключ" >> ~/.ssh/authorized_keys

## Восстановление доступа

Потеряли ключ — консоль хостера (VNC) под root: пароль root скрипт не меняет, отключён только
вход root по SSH. Оттуда добавьте новый ключ пользователю `proxyadmin`.

## Повторный запуск

Скрипт идемпотентен: выполненные шаги отмечаются в `/root/proxy-server/state/` и не повторяются.
Ключи и ссылка при повторном запуске не меняются.

Пересоздать всё с нуля: `rm -rf /root/proxy-server` и запустить снова (старая ссылка перестанет работать).

## Настройки

Переопределяются переменными окружения перед командой:

    NEW_USER=admin SSH_PORT=22 XRAY_PORT=443 REALITY_DEST=www.microsoft.com bash <(curl ...)

## Безопасность

- Пароли не сохраняются нигде, кроме `output/README.txt` (права 600, только root).
- Вход root и вход по паролю отключаются только после вашего подтверждения.
- Открыты только два порта; остальные входящие соединения запрещены.
- Reality не требует домена и сертификата — трафик выглядит как обращение к обычному сайту.
